# Forex Platform

Quantitative Forex Trading and Backtesting Platform.

## Milestone 1: Foundation & Core Engine
- Precision pip math with exact rounding and decimal representation
- 24/5 Forex session state machine (Sydney, Tokyo, London, New York, Weekend, Rollover, Triple Swap)
- High-performance causal market data loader & multi-timeframe downsampler
- Economic friction engine (dynamic spread, ECN commission, swap carry costs)
- CLI utilities for session and pair inspection
